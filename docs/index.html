A hybrid quantum–classical framework for contextual sensor-network representation

AQSE separates observations, eight-dimensional feature profiles, quantum encoding, and classical prediction, then evaluates a trainable quantum kernel (TQK) against classical alternatives on a controlled magnetometer task — under a repository-preregistered protocol.

01Headline result

An eight-qubit variational circuit with 16 trainable parameters defines a fidelity kernel (TQK), optimized by quantum natural gradient and read out through an SVC. It is compared against a radial-basis-function SVC baseline across 30 independently generated corpora (120 episodes each: 72 train / 24 validation / 24 test).

02Framework

AQSE connects simulated observations from one to eight magnetometers to causal, eight-dimensional local or network feature profiles (State8). An eight-qubit variational circuit (VQC) defines a trainable fidelity kernel (TQK). A regularized Nyström map (AFSE) converts kernel similarities to a fixed-dimensional classical representation, which passes to a multilayer perceptron — a classical-approximation step, not a separate quantum algorithm.

Training and inference are distinct operations: quantum natural gradient (QNG) updates circuit parameters during an explicit training job; inference uses frozen parameters and preprocessing. Versioned model bundles link each output to its feature profile, scaler, circuit parameters, landmarks, and classifier.

The replicated experiment reported here isolates the TQK component on a controlled, single-magnetometer task — discrimination between nominal and elevated white-noise regimes under harmonic excitation — using an eight-feature harmonic representation and an SVC operating directly on the quantum kernel. It does not evaluate the complete network State8–AFSE–MLP path.

03Scientific boundary

What this work does not claim

  • The network State8–AFSE–MLP demonstrator and the single-magnetometer harmonic TQK–SVC benchmark are separate routes; the 30 corpora test only the latter.
  • The TRAIN-label control keeps validation supervision and reuses one teacher dataset — a partial training-signal ablation, not a fully label-null experiment.
  • Reported QNG trajectories lack TEST evaluations for the unselected initial models.
  • No hardware advantage, field-deployment validity, or causal training benefit is claimed.

Revision passes (tracked in editorial/, six to date) have only ever defined acronyms, disambiguated units, standardized route/figure names, or removed unsupported references — never changed a frozen estimate, added an unreported experiment, or altered a displayed equation. analysis/pass4/ is the single source of truth for every number in the manuscript, with a reproduction script included.
